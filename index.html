O mne

Som junior QA tester so znalosťou manuálneho aj automatizovaného testovania. Píšem testy v Pythone, automatizujem UI testy cez Playwright, používam GitHub Actions na CI/CD a venujem sa bezpečnostnému testovaniu.

Popri tom sa systematicky vzdelávam v IT — Windows, Linux, počítačové siete a základy kybernetickej bezpečnosti. Absolvoval som kurz Python Programmer (IT Academy), aktuálne prechádzam kurzom Introduction to Security a začínam kurz Ethical Hacker (Cisco Networking Academy).

Hľadám juniorskú pozíciu v oblasti QA/testingu, IT administrácie, správy systémov alebo NOC.
